# 🌾 Portal de Cotação

> Sistema web desenvolvido para digitalizar e automatizar o processo de cotações entre colaboradores e fornecedores, proporcionando maior agilidade, organização e transparência nas compras da empresa.

---

## 📖 Sobre o Projeto

O Portal de Cotação é uma aplicação web criada para substituir o processo manual de solicitação e recebimento de cotações de materiais utilizados.

Anteriormente, as solicitações eram realizadas por meio de planilhas, e-mails e mensagens, tornando o processo lento, descentralizado e sujeito a erros.

Com este sistema, todo o fluxo de cotação passa a ser centralizado em uma única plataforma, permitindo que colaboradores criem solicitações de compra e fornecedores enviem suas propostas de forma simples, segura e organizada.

---

## 🎯 Objetivo

O principal objetivo do projeto é automatizar o processo de compras da empresa, oferecendo uma plataforma onde colaboradores e fornecedores possam interagir de forma eficiente durante todo o ciclo de cotação.

O sistema busca:

- reduzir processos manuais;
- diminuir o tempo de resposta dos fornecedores;
- facilitar a comparação de preços;
- aumentar a organização das solicitações;
- manter um histórico das negociações;
- proporcionar maior transparência durante todo o processo de compra.

---

## 🏗 Arquitetura

O projeto foi desenvolvido utilizando a arquitetura MVC (Model-View-Controller), proporcionando maior organização do código e separação das responsabilidades.

---

## 💻 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- Thymeleaf
- Bootstrap 5
- HTML5 e CSS3
- JavaScript
- Maven
- H2 Database (desenvolvimento)
